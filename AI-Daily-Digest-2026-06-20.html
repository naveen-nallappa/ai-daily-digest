Infosecurity Magazine

'Agentjacking' Hijacks Coding Agents via Fake Sentry Bug Reports

Security firm Tenet disclosed a technique it calls "agentjacking" that hijacks AI coding agents — Claude Code, Cursor and Codex — when a Sentry error-monitoring connector is attached. Attackers inject fake error events using a public credential; the agent reads the planted "fix" steps and runs malicious commands with the user's own privileges, exposing AWS keys, npm tokens and git credentials. During testing that ended June 17, researchers found 2,388 organizations with exposed Sentry identifiers and confirmed an 85% success rate. Standard EDR, IAM and VPN controls did not stop it.

Why it matters: As advisors and asset managers wire coding and workflow agents into production, this shows untrusted data fed through a connector can turn an agent into an attacker with the user's access. Technology and risk teams should inventory which MCP connectors their agents trust, restrict agent privileges, and require human approval before any agent executes shell commands or installs packages.
